# Paraclete

*"One called alongside to help"* - nudge reminders that fire AROUND a time,
not at it.

Your reminders and categories live inside an `.xlsx` file that you choose
the location of. Paraclete reads and writes that file directly - there's no
account, no server, and no sign-in. If you want reminders that respect real
life's timing instead of a rigid alarm, or you want full control over your
own data in a format you can open anywhere, that's what Paraclete is for.

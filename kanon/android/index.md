# Android

Standards for Kotlin and Jetpack Compose apps.

Read [Project Setup](project-setup.md) first when starting a new app,
then check [Proven Version Pairings](version-pairings.md) for a
ready-to-use AGP/Gradle/Kotlin/KSP/Hilt combo before researching one
from scratch, then [App Shell](app-shell.md) before the second screen
exists, then [Theming](theming.md) when branding lands, then
[Feature Patterns](feature-patterns.md) once billing, crash reporting, or
an onboarding tour comes up. If the app is spreadsheet-first (Apache POI
as the database), read [Spreadsheet Architecture](spreadsheet-architecture.md)
before the first tab gets written.

[Troubleshooting](troubleshooting.md) is a lookup table rather than a
read-through — symptom, to root cause, to fix.

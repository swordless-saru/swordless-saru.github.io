# What's New

Dragma hasn't had its first public release yet - this page will list
user-facing highlights for each version once it does.

When a release ships, the entry here is authored fresh from that release's
actual user-facing changes - it is not generated from the project's internal
engineering changelog, which tracks implementation detail this page
deliberately leaves out.

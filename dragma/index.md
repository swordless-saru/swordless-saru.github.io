# Dragma

Spreadsheet-first budgeting for Android.

Your accounts, transactions, categories, and recurring templates live inside
an `.xlsx` file that you choose the location of. Dragma reads and writes
that file directly - there's no account, no server, and no sign-in. If you
already use a spreadsheet to track money, or you want full control over
your own data in a format you can open anywhere, that's what Dragma is for.

# swordless-saru.github.io

Source for [swordless-saru.github.io](https://swordless-saru.github.io/),
the Tri-Tail Digital portfolio hub - lists every live app and engineering
standards site (Dragma, Paraclete, Kanon), so a visitor to any one of them
can find the others in one place.

Built with Jekyll + the [just-the-docs](https://just-the-docs.com/) theme,
same as every individual app's own docs site. See `index.md` for the actual
content; `_config.yml` for the site setup.
